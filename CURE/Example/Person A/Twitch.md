
## Compilation

Compilation videos (e.g. fan-made comps of a streamer) are about one
identifiable person. They go into this separate `## Compilation`
section, above the table, as a plain list of links, analogous to the Youtube file. See the example
there for details.

- https://twitch.tv/streamer/compilationVOD
- ...

## Timestamps

Be sure to include a table with both Links (for the actual Link) and TS (for the timestamps) columns. The TS column can be empty if it is a short clip, but should be filled for long-form content.

Timestamps can be given in the following format:
- 1:23 
	- Meaning the event occurs around 1:23 in the linked media.
- 1:23 (x2)
	- Meaning the event occurs twice around 1:23 in the linked media
- 1:23 (amazing!)
	- To tag the event around 1:23 with some additional information
- 1:23 - 2:34
	- The event(s) occur between 1:23 and 2:34 in the linked media
Multiple timestamps or additions in parentheses should be divided by comma. 
Timestamps must be sorted in ascending order.

| Link                             | TS  |
| -------------------------------- | --- |
| https://twitch.tv/someRandomClip |     |
| ...                              |     |
