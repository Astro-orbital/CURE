
## Compilation

Compilation videos (e.g. fan-made comps of a streamer/VODs) are about one
identifiable person. They go into this separate `## Compilation`
section, above the table, as a plain list of links. A compilation of a compilation channel not clearly containing one identifiable persons does not belong here.

- https://youtube.com/someCompilationOfThisPerson
- ...

## Timestamps

Be sure to include a table with both Links (for the actual Link) and TS (for the timestamps) columns.

Timestamps can be given in the following format:
- 1:23 
	- Meaning the event occurs around 1:23 in the linked media.
- 1:23 (x2)
	- Meaning the event occurs twice around 1:23 in the linked media
- 1:23 (amazing!)
	- To tag the event around 1:23 with some additional information
- 1:23 - 2:34
	- The event(s) occur between 1:23 and 2:34 in the linked media
Multiple timestamps or additions in parentheses should be divided by comma. 
Timestamps must be sorted in ascending order. 

| Link                                | TS   |
| ----------------------------------- | ---- |
| https://youtube.com/someRandomVideo | 1:23 |
| https://youtube.com/someOtherVideo  | 2:34 |
| ...                                 | ...  |
